# 🕐 Dynamic Clock — Modern Way

A modern, minimal **analog clock** with concentric rings that show the **date, month and weekday** in real time. Built with pure **HTML, CSS and JavaScript** — no libraries, no build step.

🔗 **Live Demo:** https://ashubrahman26-max.github.io/Dynamic-clock/

## ✨ Features

- Analog clock with smooth hour, minute and second hands
- Concentric rings for **date**, **month** and **weekday**
- Current date, weekday, month and year shown below the clock
- Date ring adjusts automatically to the real number of days in the month
- Active values highlighted with colour and glow
- Fully responsive (desktop + mobile)
- Respects `prefers-reduced-motion`
- Single file, zero dependencies

## 🚀 Usage

1. Download or clone this repo
2. Open `index.html` in your browser

```bash
git clone https://github.com/ashubrahman26-max/Dynamic-clock.git
```

## 🎨 Customization

Change colours from the `:root` block at the top of the CSS:

```css
:root{
  --accent:#6be26b;     /* weekday highlight */
  --accent2:#4da6ff;    /* month highlight */
  --highlight:#ff3b6b;  /* date + second hand */
}
```
